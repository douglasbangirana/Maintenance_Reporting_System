# MMU FixIt: Campus Maintenance Reporting System
BSE 4103 Advanced Internet Programming, progressive coursework (Weeks 1-4 complete).

## Run locally (Week 1: use a web server, not file://)
    npm start        # serves on http://localhost:3000

## Features by week
- Week 1: Home, About, Services, report form, navigation; Git + deployment
- Week 2: Semantic HTML5, external CSS, mobile-first Flexbox/Grid, media queries at 768px and 1024px, viewport meta, responsive nav/cards/form/footer
- Week 3: ES6+ (const/let, arrows, template literals, destructuring, spread), async/await + Fetch to Open-Meteo, loading and error states with retry
- Week 4: DOM selection/creation, event listeners (click, input, blur, change, submit), full validation with inline messages, submit blocked while invalid, live report list with filter and delete (saved in localStorage until the Week 5 server)

## Tested viewports
360px, 768px, 1024px, 1440px
